# 自学サポート

小学1〜6年生が「何を・なぜ・どうやって学ぶか」を自分で決め、紙のノートで家庭学習を進めるためのWebアプリです。低学年は短く具体的に、高学年は復習・整理・調べ学習へと広げられるメニューを用意しています。

最終ゴールは、このアプリを使い続けることではありません。子どもがアプリを見なくても、自分で自学を決め、確かめられるようになることです。

## 学習の流れ

`決める → やり方を確認する → ノートで学ぶ → 確かめる`

- 今日の気持ち・時間・教科から3候補を提案
- 249件の自学メニューを学年・教科・型・時間で検索
- 4つの型（解く／まとめる／調べる／覚える）からノート上の手順を案内
- ホームで学年を選び、その学年で扱う教科から自学候補を提案
- 学年・教科に合わせて、TT-senseiの既存学習アプリへ直接移動
- テスト予定と学習記録を端末内に保存
- 学習記録カレンダーから、日ごとに何をしたかを確認

記録は端末内のlocalStorageに保存されます。ランキング、連続日数による罰、ページ数評価、アカウント、通信、AI APIはありません。

## メニュー数

| 教科 | 件数 |
| --- | ---: |
| 国語 | 53 |
| 算数 | 65 |
| 理科 | 44 |
| 社会 | 44 |
| 英語 | 15 |
| 生活 | 8 |
| 教科横断 | 20 |
| 合計 | 249 |

低学年には、ひらがな・文づくり・数の見方・たし算やひき算・生活の観察など、短時間で始めやすいメニューを追加しています。算数は第4学年の面積と第5学年からの体積を分け、外国語は3・4年生の音声中心の活動と5・6年生の語句・読み書きの課題を区別しています。既存のメニューは削除せず、既存IDを維持したまま末尾に追加しています。

各メニューは `id / subject / title / type / grades / difficulty / minutes / purposes / whenToUse / materials / goalExample / instruction / customSteps / reflectionPrompts / testRecommended / relatedResources` を持ちます。

## 学年の考え方

学年表示は、文部科学省の小学校学習指導要領・各教科解説を目安に、学習内容の開始時期や活動の負担に合わせて整理しています。外国語は、3・4年の音声中心の活動と、5・6年で扱う語句・読み書きの活動を区別しています。メニューは現在の単元や教科書の進度と完全に一致するものではありません。授業で習った内容や、先生・家族と相談した内容を優先してください。

参照：
- [小学校学習指導要領解説（文部科学省）](https://www.mext.go.jp/a_menu/shotou/new-cs/1387014.htm)
- [小学校学習指導要領（文部科学省）](https://www.mext.go.jp/a_menu/shotou/new-cs/youryou/syo/index.htm)

## 技術

HTML / CSS / Vanilla JavaScriptのみ。ビルド不要でGitHub Pagesから動作します。保存には `edu-components` の `StorageManager` をローカル同梱して使い、`edu:jigaku-coach-v1:*` のnamespaceに集約しています。

Web画像は既存のNAVI CHARACTER素材とedu-assetsを参照し、画像が読み込めない場合も学習導線は止まりません。
