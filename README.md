# 自学サポート

**自分で選び、紙のノートで学ぶ力を育てる、小学1〜6年生向けのWebアプリです。**

「何を勉強したらいいか分からない」ときに、学年や気分、使える時間に合わせて自学の候補を探せます。アプリは学習内容を決める手助けをしますが、実際に考えたり、書いたり、確かめたりするのはノートの上です。

目指しているのは、アプリを使い続けることではありません。やがて子どもがアプリを開かなくても、自分で学ぶことを決め、学び方を工夫できるようになることです。

**公開ページ：** https://tt-sensei.github.io/jigaku-supports/

## 使い方

1. 学年を選びます。選んだ学年はこの端末に保存されます。
2. 今日の気分や目的、使える時間などを手がかりに、取り組む課題を探します。
3. 課題の説明と進め方を確認します。
4. 紙のノートで学習します。
5. 必要に応じて、学習アプリや参考資料で確かめます。
6. 学習した内容を記録し、あとから振り返ります。

## 課題の選び方

メニューは、子どもが次の行動を想像しやすいよう、具体的な題名と手順で構成しています。

- **まずはここから：** 選んだ学年の各教科から、取り組みやすい課題を最大3つずつ表示します。候補を絞り、迷わず始めるための入口です。
- **すべてのメニュー：** 収録された課題を一覧で探せます。
- **絞り込み・検索：** 学年、教科、課題の型、所要時間などで候補を絞り、ことばでも検索できます。

課題は、主に次の4つの型で進めます。

| 型 | 取り組み方 |
| --- | --- |
| 解く | 自分で解き、答えを確かめ、間違いを直す |
| まとめる | 大切なことを選び、言葉・図・表などで整理する |
| 調べる | 疑問や予想をもち、資料を使って分かったことをまとめる |
| 覚える | 見て覚え、隠して試し、間違いを確かめてもう一度試す |

## 学習記録とプライバシー

- 学習記録カレンダーで、日ごとに取り組んだ内容を振り返れます。
- テスト予定や設定、学習記録は、ブラウザーの `localStorage` を使って利用中の端末に保存します。
- サーバーへの学習記録送信、アカウント登録、ランキング、AI APIは使用しません。
- ブラウザーのデータを削除した場合などは、保存した記録が消えることがあります。必要な記録は別途ノートなどにも残してください。

## TT-senseiの学習アプリ・参考資料

課題に応じて、関連するTT-senseiの学習アプリや参考資料へ移動できます。必要なときにデジタル教材を使い、中心となる学習は紙のノートで行う設計です。

画像素材は既存のNAVI CHARACTER素材やedu-assetsを参照しています。画像が読み込めない場合でも、課題を選んで学習する基本の流れを妨げないことを目指しています。

## 技術とファイル構成

HTML・CSS・JavaScriptで構成した静的Webアプリです。ビルド工程やバックエンドは不要で、GitHub Pagesで公開しています。

- `index.html` — アプリの入口、共通ヘッダー、学年選択
- `style.css` — レイアウトとレスポンシブ表示
- `app.js` — 画面表示、課題の推薦・検索、関連リンク、予定・記録の管理
- `data/menus.js` — 自学メニューと4つの型のテンプレート
- `vendor/storage-manager.js` — 端末内の保存処理

保存処理には、`edu-components` の `StorageManager` をローカル同梱して利用しています。保存領域のnamespaceは `jigaku-coach-v1` です。これは内部の保存キーであり、アプリの表示名は「自学サポート」です。

設計・開発では、[TT-sensei/edu-kit](https://github.com/TT-sensei/edu-kit) の設計原則や開発プロトコルを参考にしています。
